PHYSICAL REPRESENTATION — CURRENT STATUS
Pepper's Ghost is a low-cost focal floating-image proof, but has a restricted viewing cone and contrast/alignment/ambient-light constraints; it is not a true volumetric hologram or a landscape base.
Projection-mapped physical relief better expresses terrain, water, settlements, routes and the landscape as spatial geometry; it requires fabrication, calibration and room-light testing.
Hybrid relief + projection + optional Pepper's Ghost focal layer + separate evidence display is the strongest current exhibition hypothesis only after separate low-cost A/B tests demonstrate measurable value.
Recommendation: maintain a presentation-neutral software core. Test both low-cost approaches using the same supported scene. Consider the hybrid only if it adds comprehension; no expensive hardware purchase before tests and Judy ma'am's path become clear.

EVIDENCE MODEL
Source -> Evidence -> Entity -> Historical State -> Scene Pack -> Presentation Client.
Separate documented claims, archaeological observations, scholarly interpretations, AI-assisted proposals and uncertainty. Record provenance, time fields, transformations, rights, confidence basis, reviewer and gaps. Modern environmental layers are not direct evidence of Chola-era states.
