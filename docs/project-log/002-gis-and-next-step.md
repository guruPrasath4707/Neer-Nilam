# Project Log 002 — Source Research → Hologram Decision Stage

Date: 2026-10-07
Status: Next step initiated

## Current understanding

Neer-Nilam is a source-aware, spatiotemporal digital heritage intelligence system with immersive presentation clients.

The hologram is the interface, not the entire product.

## DeepSeek baseline

DeepSeek recommended:
- Pepper's Ghost as a practical optical prototype
- rotary encoder as reliable primary control
- optional depth camera
- discrete/event-based historical states
- evidence/provenance/uncertainty
- one monument first
- no true volumetric claims for the pilot

These are hypotheses, not final commitments.

## New source-research contribution

The Bhuvan, Overpass and TNGIS review adds:
- master website index
- Source Registry
- Data Rights layer
- raw/restricted versus public/derived separation
- source-aware connectors
- scene composer

## Immediate question

Which physical presentation architecture should the first Neer-Nilam prototype use?

We must compare actual 2026 options and products rather than selecting a technology purely because it looks futuristic.

Candidate families:
- Pepper's Ghost / beamsplitter
- transparent OLED/LCD
- holographic pyramid
- LED fan
- projection mapping
- light-field
- volumetric
- AR/MR
- hybrid optical/display systems

## Selection criteria

- image quality
- apparent depth/parallax
- brightness/contrast
- viewing cone
- audience size
- interaction
- latency
- room lighting
- dimensions
- portability
- safety
- maintenance
- hardware availability in India
- software/API integration
- cost
- reliability
- fallback behavior

## Gate

No expensive hardware purchase until the technical and market comparison is complete and a low-cost proof validates the chosen presentation geometry.
