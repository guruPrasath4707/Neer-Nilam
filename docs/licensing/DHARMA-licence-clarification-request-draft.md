# DHARMA Licence Clarification Request — Draft Only

**Status:** Draft prepared; not sent.  
**Purpose:** Obtain authoritative written clarification before redistribution or production of reusable derivatives.

**Suggested recipient:** DHARMA project contact listed in the repository README: ercdharma@gmail.com  
**Repositories:**
- https://github.com/erc-dharma/tfa-tamilnadu-epigraphy
- https://github.com/erc-dharma/tfa-sii-epigraphy

## Suggested subject

Clarification requested: repository-level CC BY 4.0 statement vs per-file CC BY-SA 4.0 declarations

## Draft message

Dear DHARMA team,

I am evaluating the DHARMA Tamil Nadu epigraphy and South Indian Inscriptions corpora for a research and scientific-heritage education prototype. Before using either corpus in a public-facing product or distributing any data or derived resources, I would like to confirm the intended licensing terms.

The repository README for the Tamil Nadu corpus states that edited XML files are available under Creative Commons CC BY 4.0. However, individual XML records that I inspected contain EpiDoc licence declarations pointing to CC BY-SA 4.0. For example:

- Tamil Nadu corpus example: https://github.com/erc-dharma/tfa-tamilnadu-epigraphy/blob/master/DHARMA_INSTamilNadu00031.xml
- South Indian Inscriptions example: https://github.com/erc-dharma/tfa-sii-epigraphy/blob/master/DHARMA_INStfaSIIv05p1i0228.xml

In the collected snapshots I audited, the local inventory recorded 340 Tamil Nadu corpus XML files and 167 South Indian Inscriptions XML files with CC BY-SA 4.0 declarations. Another 16 and 30 files respectively had no detected licence target in that inventory. These counts describe my captured snapshots, not a claim that the current repositories have identical contents.

Could you please clarify:

1. Is CC BY 4.0 intended to apply to every edited XML file in both repositories, including records whose own XML currently declares CC BY-SA 4.0?
2. If both declarations are intentional, which licence should a user follow for each affected file, and is there an authoritative per-file licence inventory or correction plan?
3. What terms apply to records for which no licence target is present or detectable?
4. For an educational application, what attribution should accompany transcriptions, metadata, quotations, translations, normalized text, search indexes and other extracted or transformed representations? When does CC BY-SA 4.0 apply to a derivative or adaptation?
5. Is redistribution of the XML files themselves permitted under the intended terms, and are there specific exclusions or additional restrictions we should respect?

Until I receive clarification, I am retaining provenance records and keeping the affected corpus and reusable derivatives on hold. I will not assume that the absence of a detected XML licence means a record has no copyright or is unrestricted.

Thank you for your time and for the work invested in these corpora. Any authoritative documentation or guidance you can provide will be preserved with the project’s source and rights records.

Kind regards,  
Neer-Nilam project research team
