# Project Baseline 001 — What We Have So Far

## Neer-Nilam

A spatiotemporal digital heritage intelligence platform for Tamil Nadu.

## Original funding vision

The funding concept combines:
- 3D GIS
- AI-assisted manuscript/inscription reconstruction
- historical knowledge graphs
- water-heritage intelligence
- archaeological/architectural evidence
- modern hydrological/environmental context

Pilot focus:
Thanjavur–Kumbakonam–Cauvery heritage corridor.

## Holographic extension

The physical installation is a presentation layer for the core system.

Desired experience:
time → monument → landscape → water → people/events → evidence.

## Current first prototype hypothesis

A Pepper's Ghost-style installation is a candidate.
A physical rotary controller is a candidate.
Gesture/depth tracking is optional.
One monument should be used for the first physical proof.

## Strongest differentiator

Not “hologram”.

The intended differentiator is an evidence-aware temporal heritage scene in which:
- historical states are traceable
- uncertainty is visible
- sources are linked
- water/land context is connected
- the same underlying system can feed web and immersive clients

## New architecture requirements

- website index tracking every research website
- source registry
- data rights
- restricted/raw versus public/derived separation
- canonical spatiotemporal model
- evidence engine
- temporal engine
- scene composer
- replaceable presentation clients

## Immediate milestone

Select a physical presentation architecture based on current technical and market research, then define one measurable prototype goal.
